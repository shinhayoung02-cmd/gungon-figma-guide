# 1. 프로젝트 정의

궁온은 관람객이 하나의 역사적 인물을 선택하고,  
실제 경복궁을 그 인물의 시선으로 바라보며,  
공간과 연결된 대표 프로그램을 직접 체험하는 관람 시스템이다.

궁온의 목적은 역사 정보를 더 많이 보여주는 것이 아니다.

**누구의 시선으로 공간을 볼 것인지 정하고,  
그 공간에서 실제로 어떤 일이 있었는지 이해하며,  
공간의 기능과 연결된 행동을 직접 경험하고,  
그 경험을 관람 후에도 다시 확인할 수 있게 하는 것**

을 핵심으로 한다.

---

# 2. 프로젝트 목표

## 기존 관람

```text
설명판
→ 오디오
→ 도슨트
→ QR
→ 사진 촬영
```

정보를 읽고 듣는 방식이 중심이었다.

## 궁온

```text
서비스 이해
→ 인물 선택
→ 공간 해석
→ 역사적 사건 이해
→ 직접 체험
→ 결과 기록
→ 관람 후 다시 보기
```

### 핵심 전환

> **역사를 보는 관람에서, 역사 속 인물의 시선으로 공간을 이해하고 행동으로 경험하는 관람으로 전환한다.**

# 3. 문제 정의

현재 경복궁에는 설명판, 오디오, 도슨트, QR 등  
여러 역사 정보 채널이 이미 있다.

문제는 정보 자체가 부족한 것이 아니라,

**실제 공간을 어떤 관점으로 바라봐야 하는지,  
무엇을 중심으로 봐야 하는지,  
그리고 공간의 의미를 어떻게 직접 경험할 수 있는지에 대한 구조가 부족하다는 점**

이다.

---

## 3.1 관람의 관점 부족

사용자는 역사 정보가 없어서가 아니라  
어떤 시선으로 공간을 바라봐야 하는지 기준이 부족하다.

### 주요 문제

- 설명이 사실 나열에 가까움
- 무엇을 중심으로 봐야 하는지 알기 어려움
- 공간마다 중요한 지점을 판단하기 어려움
- 같은 공간을 다른 인물의 입장에서 보는 경험이 부족함

---

## 3.2 수동적인 이해

읽고 듣는 정보는 많지만  
사용자가 직접 경험했다는 느낌은 부족하다.

### 주요 문제

- 행동을 통한 역사 체험 부족
- 사진만 찍고 지나가기 쉬움
- 다른 관람객의 흐름을 따라가기 쉬움
- 공간이 실제로 어떤 기능을 했는지 체감하기 어려움

---

## 3.3 경험의 연속성 부족

각 공간에서 경험한 내용이 따로 남아  
하나의 관람 경험으로 이어지기 어렵다.

### 주요 문제

- 어떤 공간에서 무엇을 했는지 기억이 흩어짐
- 완료한 체험을 한눈에 보기 어려움
- 프로그램 결과를 다시 보기 어려움
- 관람 이후 경험을 이어갈 구조가 부족함

---

# 4. 핵심 질문

> **관람객이 역사 속 인물의 관점으로 실제 경복궁을 바라보고, 공간에서 일어난 사건을 이해하며, 공간과 연결된 행동을 직접 경험한 뒤 그 결과를 하나의 관람 기록으로 이어가게 할 수 있을까?**

### 핵심 요구

# 7. 경험 구조

기존에는 서비스를

```text
WEB
SMART GLASS
INTERACTIVE SCREEN
```

처럼 기기 기준으로 구분했다.

하지만 이 방식은  
각 기기에서 무엇을 하는지는 잘 보이지만

- 사용자가 어떤 순서로 경험하는지
- 경험이 다음 단계로 어떻게 이어지는지
- 관람 후에는 무엇이 남는지

가 충분히 보이지 않았다.

따라서 서비스의 가장 상위 구조를  
**사용자의 경험 단계**로 변경한다.

---

## 7.1 준비

### 의미

서비스를 이해하고 현장 경험을 준비한다.

### 주요 경험

- 서비스 이해
- 이용 방법 확인
- 언어 / 접근성 확인

### 주요 접점

**WEB**

---

## 7.2 해석

### 의미

선택한 인물의 시선으로  
실제 경복궁 공간과 역사를 이해한다.

### 주요 경험

- 왕 / 왕비 / 세자 선택
- 현재 전각 확인
- 인물 기반 공간 해석
- 역사적 사건 확인
- 핵심 지점 확인

### 주요 접점

**SMART GLASS**

---

## 7.3 체험

### 의미

공간에서 이해한 내용을  
직접 행동하며 경험한다.

### 주요 경험

- 선택
- 조작
- 쓰기
- 배치
- 결과 확인

### 주요 접점

**INTERACTIVE SCREEN**

---

## 7.4 기록 · 확장

### 의미

현장에서 만든 경험을 기록하고  
관람 이후에도 다시 이어간다.

### 주요 경험

- 완료 프로그램 확인
- 프로그램 결과 확인
- 경험한 공간 확인
- 관람 기록 다시 보기
- 굿즈 미리보기
- 선택 구매
- 일상에서 경험 다시 떠올리기

### 주요 접점

**WEB + CUSTOM GOODS**

# 9. 서비스 원칙

궁온의 기능과 화면을 결정할 때  
다음 5개 원칙을 기준으로 판단한다.

---

## 원칙 01. 모든 경험은 실제 공간에서 시작한다

**궁온의 모든 정보와 체험은 실제 경복궁 공간과 연결되어야 한다.**

궁온은 화면 안에서 역사를 보여주는 서비스가 아니라,  
사용자가 지금 보고 있는 실제 공간을 더 잘 이해하고 경험하도록 돕는 서비스다.

### 적용 기준

- 제공하는 정보는 현재 보고 있는 공간과 연결한다.
- 역사적 사건은 실제 해당 공간을 바라보며 경험하게 한다.
- 핵심 지점은 실제 건축물이나 공간에서 확인할 수 있어야 한다.
- 체험 프로그램도 해당 공간의 역사적 기능과 연결한다.
- 실제 공간과 관계없는 콘텐츠는 핵심 경험에서 제외한다.

### 판단 질문

> **이 경험이 지금 보고 있는 실제 경복궁 공간과 연결되어 있는가?**

---

## 원칙 02. 정보를 나열하지 않고, 바라보는 관점을 제공한다

**같은 공간도 누구의 시선으로 보느냐에 따라 다르게 이해할 수 있게 한다.**

궁온은 역사 정보를 많이 보여주는 것보다,  
사용자가 공간을 어떤 기준으로 바라볼지 알려주는 것을 중요하게 본다.

Smart Glass의 정보는 다음 세 가지로 구분한다.

```text
인물
누구의 시선으로 볼 것인가

+

사건
이 공간에서 무슨 일이 있었는가

+

핵심 지점
무엇을 주목해서 볼 것인가
```

### 적용 기준

- 단순한 역사 정보 나열로 끝내지 않는다.
- 선택한 인물과 공간의 관계를 먼저 보여준다.
- 역사적 사건은 현재 보고 있는 공간과 연결한다.
- 핵심 지점을 통해 실제로 무엇을 봐야 하는지 알려준다.

### 판단 질문

> **이 정보가 사용자가 공간을 바라보는 방식을 바꿔주는가?**

---

## 원칙 03. 이해한 내용은 직접 체험으로 이어진다

**보고 이해한 공간의 의미를 직접 행동하며 경험한다.**

Smart Glass에서 공간을 이해한 뒤  
Interactive Screen에서는 그 공간과 연결된 행동을 직접 수행한다.

```text
본다
↓
이해한다
↓
직접 체험한다
↓
결과가 남는다
```

### 적용 기준

- Smart Glass에서 설명을 보고 끝나지 않는다.
- 체험은 해당 공간의 역사적 기능과 연결한다.
- 선택 · 쓰기 · 배치 · 조작처럼 사용자가 직접 행동하게 한다.
- 단순 퀴즈나 영상 시청만으로 체험을 구성하지 않는다.
- 사용자의 행동에 따라 결과가 만들어지도록 한다.

### 판단 질문

> **이 체험이 방금 이해한 공간의 의미를 직접 느끼게 하는가?**

---

## 원칙 04. 각 경험은 끊기지 않고 이어진다

**한 접점에서 만든 경험과 결과가 다음 단계로 자연스럽게 이어져야 한다.**

WEB, Smart Glass, Interactive Screen을  
각각 따로 사용하는 기기로 보지 않고  
하나의 관람 흐름 안에서 연결한다.

```text
WEB
서비스 이해

↓

SMART GLASS
공간 해석

↓

INTERACTIVE SCREEN
직접 체험

↓

WEB
관람 기록

↓

CUSTOM GOODS [선택]
실물로 확장

↓

일상
경험 다시 떠올리기
```

### 적용 기준

- WEB에서 이해한 내용이 현장 경험으로 이어진다.
- Smart Glass의 공간 이해가 Interactive Screen의 체험으로 이어진다.
- Interactive Screen의 결과가 WEB의 관람 기록으로 이어진다.
- 관람 기록은 관람 후에도 다시 확인할 수 있다.
- 같은 기능을 여러 기기에서 반복하지 않는다.
- 다음 단계로 이동해야 하는 이유를 사용자가 이해할 수 있어야 한다.

### 판단 질문

> **이 경험이 끝난 뒤 사용자는 다음에 무엇을 해야 하는지 자연스럽게 알 수 있는가?**

---

## 원칙 05. 관람 방식은 사용자가 선택한다

**궁온이 정해진 체험을 강요하지 않고, 사용자가 자신의 속도와 방식으로 관람할 수 있게 한다.**

궁온은 모든 콘텐츠를 완료해야 하는 게임이 아니다.  
사용자는 필요한 경험을 선택하면서 실제 경복궁 관람을 이어갈 수 있다.

### 적용 기준

- 프로그램 참여를 강제하지 않는다.
- 모든 공간 방문을 요구하지 않는다.
- 프로그램을 건너뛰어도 관람을 계속할 수 있다.
- 굿즈 구매를 서비스 완료 조건으로 만들지 않는다.
- 점수 경쟁을 만들지 않는다.
- 엽전이나 스탬프 수집을 사용하지 않는다.
- 특정 순서대로 모든 경험을 완료하도록 강제하지 않는다.

### 판단 질문

> **사용자가 원하지 않는 경험까지 하도록 강요하고 있지는 않은가?**

# 10. 서비스 시나리오

서비스 시나리오는  
화면이 어떤 순서로 나오는지만 정리하는 것이 아니다.

**사용자가 어떤 상황에서 무엇을 보고, 무엇을 이해하고, 어떤 행동을 하는지 하나의 이야기로 연결하는 것**이다.

궁온은 시나리오를 세 단계로 나눈다.

```text
01 전체 이야기
이상적으로 어떤 경험을 하는가

02 주요 흐름
실제로 어떤 순서로 사용하는가

03 문제 상황
흐름이 깨졌을 때 어떻게 대응하는가
```

# 11. 전체 이야기

경복궁을 방문한 관람객은  
방문 전 궁온 웹에서 서비스와 이용 방법을 확인한다.

현장에 도착하면 Smart Glass를 대여하고 착용한다.

관람객은 이번 관람에서 경복궁을 바라볼 인물로  
왕, 왕비, 세자 중 한 명을 선택한다.

관람을 시작하면 Smart Glass는  
현재 사용자가 보고 있는 전각을 인지한다.

이후 선택한 인물과 공간의 관계를 보여주고,

- 이 공간이 선택한 인물에게 어떤 의미였는지
- 이곳에서 실제로 어떤 일이 있었는지
- 실제 공간에서 무엇을 주목해서 봐야 하는지

를 확인할 수 있게 한다.

프로그램이 있는 공간에 도착하면  
Smart Glass가 프로그램이 있다는 것을 알려준다.

사용자가 참여를 선택하면  
Interactive Screen으로 이동한다.

Interactive Screen에서는  
Smart Glass에서 이해했던 역사적 내용과 연결된 행동을 직접 수행한다.

예를 들어

- 오늘의 수라상에서는 왕실 음식과 상차림을 선택하고 배치하며
- 훈민정음 서재에서는 글을 쓰고 조작하는 과정을 경험한다.

프로그램을 완료하면  
사용자의 선택과 행동에 따른 결과가 만들어진다.

이 결과는 현장에서 한 번 보고 끝나는 것이 아니라  
WEB의 나의 관람 기록에 저장된다.

사용자는 다시 Smart Glass를 통해  
실제 경복궁 관람으로 돌아간다.

관람이 끝난 뒤 Smart Glass를 반납하고  
WEB에서

- 오늘 선택한 인물
- 경험한 주요 공간
- 완료한 프로그램
- 프로그램 결과

를 다시 확인한다.

원하는 경우 자신의 인물과 프로그램 결과가 적용된  
커스텀 굿즈를 미리 보고 선택적으로 구매할 수 있다.

관람 이후에도 WEB의 기록이나 굿즈를 통해  
그날의 경복궁 경험을 다시 떠올릴 수 있다.

# 14. 문제 상황과 대응

## 14.1 Smart Glass가 공간을 인식하지 못함

```text
공간 인식 실패
↓
잘못된 내용 제공하지 않음
↓
기본 관람 상태 유지
↓
재인식 시도
↓
계속 실패하면 최소 안내 제공
```

### 원칙

> **확실하지 않은 역사 정보를 임의로 제공하지 않는다.**

---

## 14.2 Interactive Screen이 사용 중

### 대응

- 기다림을 강제하지 않음
- 프로그램을 건너뛰고 관람 가능
- 원하는 경우 이후 다시 참여 가능

### 원칙

> **프로그램 때문에 전체 경복궁 관람이 멈추지 않도록 한다.**

---

## 14.3 사용자가 프로그램을 원하지 않음

```text
프로그램 안내
↓
참여 / 건너뛰기
↓
건너뛰기
↓
Smart Glass 관람 지속
```

프로그램은 필수 미션이 아니다.

---

## 14.4 프로그램 체험 도중 중단

- 완료된 것으로 표시하지 않음
- 미완성 결과를 완성 결과처럼 저장하지 않음
- 재시작 가능 여부는 프로그램별로 정함

---

## 14.5 프로그램 결과가 WEB에 보이지 않음

```text
프로그램 완료
↓
결과 생성
↓
시스템 저장
↓
관람 세션과 결과 연결
↓
WEB 관람 기록 반영
```

사용자가 WEB과 Smart Glass를 직접 연결하거나 관리하는 기능은 만들지 않는다.

다만 여러 접점의 결과를 하나의 관람 기록으로 묶기 위한  
**관람 세션 식별 방식**은 운영 설계에서 정해야 한다.

---

## 14.6 Smart Glass 장비 오류

```text
오류 확인
↓
현장 직원 지원
↓
필요 시 장비 교체
↓
기존 관람 기록 유지 여부 확인
```

---

## 14.7 굿즈를 구매하지 않음

아무런 불이익이 없다.

WEB의 관람 기록만으로 서비스 경험은 완결된다.

# 22. Smart Glass 운영 원칙

1. 1인칭 시점을 유지한다.
2. 왕 / 왕비 / 세자만 선택할 수 있다.
3. 이동 중에는 정보량을 최소화한다.
4. 실제 경복궁 공간보다 화면이 앞서지 않는다.
5. 긴 역사 설명보다 핵심 내용을 우선한다.
6. 역사적 사실은 검수된 내용을 기반으로 한다.
7. 공간 관람을 방해하지 않는 최소한의 방향 안내만 제공한다.

# 29. 접점 사이 연결

궁온에서는 각 기기가 무엇을 하는지만큼  
**기기 사이에서 무엇이 이어지는지**가 중요하다.

---

## 29.1 WEB → SMART GLASS

### 이어지는 경험

**서비스 이해 → 현장 경험**

WEB에서 서비스와 이용 방법을 이해한 뒤  
현장에서 Smart Glass 경험을 시작한다.

### 핵심 문장

> **이용 방법을 이해하고 현장으로**

---

## 29.2 SMART GLASS → INTERACTIVE SCREEN

### 이어지는 경험

**공간 이해 → 직접 행동**

Smart Glass에서

- 현재 공간
- 인물의 시선
- 역사적 사건
- 핵심 지점

을 이해한 뒤

Interactive Screen에서  
그 공간과 연결된 행동을 직접 수행한다.

### 핵심 문장

> **공간의 이해를 행동으로**

---

## 29.3 INTERACTIVE SCREEN → WEB

### 이어지는 경험

**행동 → 결과 → 기록**

Interactive Screen에서 만든 결과가  
WEB의 관람 기록으로 이어진다.

### 이어지는 정보

- 프로그램 이름
- 완료 상태
- 체험 결과
- 개인화에 필요한 결과 정보

### 핵심 문장

> **체험 결과를 기록으로**

---

## 29.4 SMART GLASS → WEB

### 이어지는 경험

**현장 관람 → 관람 기록**

WEB에서 확인 가능한 내용:

- 오늘 선택한 Persona
- 경험한 주요 공간
- 완료한 프로그램
- 프로그램 결과

GPS 전체 이동 경로나  
실시간 위치 추적은 핵심 기능에 포함하지 않는다.

### 핵심 문장

> **어떤 공간과 경험을 만났는지 기록으로**

---

## 29.5 WEB → CUSTOM GOODS

### 이어지는 경험

**관람 기록 → 개인화된 실물**

WEB에 남은 Persona와 프로그램 결과를  
굿즈에 적용해 미리 볼 수 있다.

```text
미리보기
↓
구매 여부 선택
↓
개인화 굿즈 제작
```

### 핵심 문장

> **기록을 실물로**

---

## 29.6 WEB / GOODS → 일상

### 이어지는 경험

**관람 경험 → 다시 떠올리기**

WEB 기록이나 굿즈를 통해  
관람 이후에도 경험을 다시 떠올릴 수 있다.

### 핵심 문장

> **현장의 경험을 일상으로**

# 32. 커스텀 굿즈

커스텀 굿즈는  
체험 완료 보상이 아니다.

## 정의

> **사용자가 자신의 관람 경험을 개인화된 실물로 남기고 싶을 때 선택적으로 구매하는 상품**

---

## 사용할 수 있는 정보

- 선택한 Persona
- 완료한 프로그램
- 프로그램 결과
- 방문 날짜
- 훈민정음 서재에서 작성한 결과
- 오늘의 수라상에서 선택한 음식 / 상차림

---

## 흐름

```text
프로그램 체험
↓
체험 결과 저장
↓
WEB에서 결과 확인
↓
커스텀 굿즈 미리보기
↓
구매 여부 선택
↓
개인화 굿즈 제작
↓
현장 수령 또는 배송
↓
일상에서 경험 다시 떠올리기
```

---

## 사용하지 않는 보상 구조

```text
체험 완료
→ 엽전 획득
→ 엽전 수집
→ 굿즈 교환
```

사용하지 않음.

```text
체험 완료
→ Digital Stamp
→ Stamp 수집
→ 무료 굿즈
```

사용하지 않음.

### 현재 원칙

- 실물 엽전 없음
- Digital Stamp 없음
- 무료 굿즈 없음
- 완료 보상형 굿즈 없음
- 굿즈 구매는 선택 사항

# 36. 관람 세션과 데이터 연결

사용자 입장에서는  
WEB, Smart Glass, Interactive Screen이 서로 다른 기기지만

서비스 안에서는 하나의 관람 경험으로 이어져야 한다.

```text
관람 세션 시작
↓
Persona 선택
↓
공간 경험
↓
프로그램 체험
↓
프로그램 결과
↓
관람 기록
↓
굿즈 미리보기
```

사용자가 직접 WEB과 Smart Glass를 연결하는 방식은 사용하지 않는다.

다만 내부적으로 결과를 한 사람의 기록에 연결할 방법은 필요하다.

# 37. 현재 추가로 정해야 할 항목

## 37.1 관람 세션 식별 방식

- 임시 관람 코드
- WEB 계정

### 현재 상태

**미확정**

### 원칙

사용자가 WEB과 Smart Glass를 직접 연결하는 복잡한 과정은 만들지 않는다.

---

## 37.2 경험한 공간 기록 범위

WEB에서 어느 공간까지 기록할지 정해야 한다.

### 추천

> **실제로 콘텐츠를 경험한 주요 공간 중심으로 기록**

GPS 전체 이동 경로는 기록하지 않는다.

---

## 37.3 관람 후 다시 떠올리기 방식

현재 확정:

- WEB에서 기록 다시 확인
- 선택한 경우 굿즈를 통해 일상에서 다시 떠올리기

아직 확정하지 않음:

- 알림 발송
- 정기적인 다시 보기 안내

- 선택한 음식 / 상차림

# 40. 검증

## 40.1 1차 검증
## 실제 관람 문제와 현재 해결안 연결 확인

### 검증 질문

> **기존 관람에서 발견한 문제가 현재 궁온의 경험 구조와 직접 연결되어 있는가?**

| 실제 관람에서 확인한 문제 | 필요한 경험 | 현재 해결안 |
|---|---|---|
| 실제 공간과 역사 설명이 충분히 연결되지 않음 | 실제 공간과 역사 내용을 함께 이해 | 인물 기반 공간 해석 + 역사적 사건 |
| 무엇을 중심으로 봐야 할지 어려움 | 관람 기준과 주목 지점 | Persona + 핵심 지점 |
| 읽고 듣는 방식 중심 | 직접 행동 | 오늘의 수라상 + 훈민정음 서재 |
| 현장 경험이 각각 따로 끝남 | 경험 결과의 연결과 기록 | Glass → Screen → WEB |
| 관람 이후 경험이 끊김 | 기록과 다시 떠올리기 | WEB 기록 + 선택형 굿즈 |

### 현재 상태

**1차 연결 관계 점검 완료**

# 44. 검증 결과 정리 방식

실제 사용자 검증 이후에는  
단순히 “좋았다 / 불편했다”로 정리하지 않는다.

| 발견한 문제 | 관찰한 근거 | 원인 | 수정 방향 |
|---|---|---|---|
| 예: Screen 사용 시점을 모름 | 사용자가 다음 행동에서 멈춤 | Glass → Screen 연결 안내 부족 | 프로그램 도착 안내 강화 |
| 예: 인물 해석과 역사 사건을 같은 정보로 인식 | 두 정보의 차이를 설명하지 못함 | 정보 역할 구분 부족 | 화면 구조와 제목 차이 강화 |
| 예: 체험 결과 위치를 찾지 못함 | WEB에서 여러 메뉴 탐색 | 결과 저장 안내 부족 | 체험 완료 시 기록 위치 안내 |

검증 이후에는

```text
프로토타입
↓
사용자 검증
↓
문제 확인
↓
수정
↓
재검증
```

과정을 반복한다.

# 48. 최종 서비스 원칙 요약

1. 실제 경복궁이 경험의 중심이다.
2. 화면보다 실제 공간을 먼저 본다.
3. 단순 정보보다 공간을 바라보는 관점을 제공한다.
4. 이해한 내용은 직접 행동으로 이어진다.
5. 각각의 접점은 다음 경험과 연결된다.
6. Persona 선택은 Smart Glass에서만 한다.
7. Smart Glass는 1인칭으로 유지한다.
8. Persona는 왕 / 왕비 / 세자만 사용한다.
9. 인물 기반 해석과 역사적 사건을 구분한다.
10. 역사 정보는 전문가 검수를 기반으로 한다.
11. AI가 역사적 사실을 임의로 만들지 않는다.
12. 프로그램 참여는 선택 사항이다.
13. WEB은 안내·현황·기록을 중심으로 한다.
14. 굿즈는 무료 보상이 아니라 선택 구매 상품이다.
15. 오류가 발생해도 실제 경복궁 관람은 계속할 수 있어야 한다.
