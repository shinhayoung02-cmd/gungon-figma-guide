# 1. 프로젝트 정의

## GUNG:ON

궁온은 관람객이 하나의 역사적 인물을 선택하고,
실제 경복궁을 그 인물의 1인칭 시선으로 바라본 뒤,
공간과 연결된 대표 프로그램에 직접 참여하는 관람 시스템이다.

단순히 역사 정보를 더 많이 제공하는 것이 아니라,

**누구의 시선으로 공간을 볼 것인지 정하고,
그 공간에서 실제로 어떤 일이 있었는지 이해하며,
공간의 기능과 연결된 행동을 직접 경험하게 하는 것**

을 핵심으로 한다.

---

# 2. 프로젝트 목표

## 기존 관람

설명판
→ 오디오
→ 도슨트
→ QR
→ 사진 촬영

처럼 정보를 읽고 듣는 방식이 중심이었다.

## 궁온

페르소나 선택
→ 공간 해석
→ 역사적 사건 이해
→ 직접 행동
→ 관람 기록
→ 관람 후 리마인드

로 경험을 확장한다.

### 핵심 전환

> **역사를 보는 관람에서, 역사 속을 직접 경험하는 관람으로 전환한다.**

---

# 3. 문제 정의

현재 경복궁에는 도슨트, 설명판, 오디오, QR 등
다양한 역사 정보 채널이 이미 존재한다.

문제는 정보 자체가 부족한 것이 아니라,

**실제 공간을 어떤 관점으로 바라봐야 하는지,
그리고 그 공간의 의미를 어떻게 직접 경험할 수 있는지에 대한 구조가 부족하다는 점**

이다.

---

## 3.1 관람의 관점 부족

사용자는 역사 정보가 없어서가 아니라
어떤 시선으로 공간을 바라봐야 하는지 기준이 부족하다.

### 주요 문제

- 설명이 사실 나열에 가까움
- 무엇을 중심으로 봐야 하는지 알기 어려움
- 공간마다 무엇이 중요한지 판단하기 어려움
- 관람객의 관점에 따라 달라지는 해석이 부족함

---

## 3.2 수동적인 이해

읽고 듣는 정보는 많지만
사용자가 직접 경험했다는 느낌은 부족하다.

### 주요 문제

- 행동을 통한 역사 체험 부족
- 사진만 찍고 지나가기 쉬움
- 다른 관람객의 흐름을 따라가기 쉬움
- 공간이 실제로 어떤 기능을 했는지 체감하기 어려움

---

## 3.3 경험의 연속성 부족

각 공간에서 경험한 내용이 따로 남아
하나의 관람 여정으로 이어지기 어렵다.

### 주요 문제

- 어떤 공간에서 무엇을 했는지 기억이 흩어짐
- 완료한 체험을 한눈에 보기 어려움
- 프로그램 결과를 다시 보기 어려움
- 관람 이후 경험과 연결되는 구조가 부족함

---

# 4. How Might We

> **관람객이 역사 속 인물의 관점으로 실제 경복궁을 해석하고,

# 8. 실제 경복궁의 역할

실제 경복궁은 디지털 터치포인트가 아니다.

## 정의

**Experience Environment / 실제 경험 환경**

궁온은 실제 궁을 가상 환경으로 대체하지 않는다.

디지털 시스템은

- 공간을 바라볼 관점을 제공하고
- 역사적 맥락을 이해하게 하고
- 공간의 기능과 연결된 행동을 유도하는

**Experience Layer**

역할을 한다.

### 핵심 원칙

> **실제 경복궁이 항상 경험의 중심에 있어야 한다.**

# 17. 페르소나 기반 콘텐츠

## 기준

**누구의 시선으로 볼 것인가**

같은 경복궁 공간이라도
왕 / 왕비 / 세자 중 누구의 관점인지에 따라
공간의 의미와 정보 우선순위가 달라진다.

### Flow

```text
페르소나 선택
↓
현재 공간 인지
↓
페르소나와 공간의 관계 판단
↓
페르소나별 공간 해석 제공
```

### 장표용 설명

> **선택한 페르소나와 현재 공간에 따라 필요한 역사 콘텐츠가 다르게 제공됩니다.**

### How

> **페르소나 선택 → 공간 인지 → 페르소나별 해석 제공**

# 18. 역사적 사건 기반 콘텐츠

기존에는 역사 장면이 페르소나 기반 콘텐츠 안에 포함되어 있었지만,
현재는 페르소나 기반 해석과 구분되는 독립적인 정보 축으로 정의한다.

## 기준

**이 공간에서 무슨 일이 있었는가**

현재 전각에서 실제로 발생했던 대표 역사 사건을
장면과 핵심 맥락 중심으로 보여준다.

### Flow

```text
현재 전각 인지
↓
해당 공간의 대표 역사 사건 확인
↓
역사 장면 제공
↓
사건의 핵심 맥락 확인
```

### 장표용 설명

> **현재 공간에서 실제로 일어났던 대표 역사 사건을 장면 중심으로 보여줍니다.**

### How

> **현재 전각 인지 → 대표 사건 호출 → 역사 장면 제공**

```

│  └─ 사건 핵심 맥락
│
├─ L4. 핵심 지점
│  ├─ 오브젝트 강조
│  ├─ 핵심 의미
│  └─ 선택 상세 정보
│
└─ L5. 프로그램 도착
   ├─ 프로그램 이름
   └─ 프로그램 도착 알림
```

---

# 22. Smart Glass 운영 원칙

1. 1인칭 시점을 유지한다.
2. 왕 / 왕비 / 세자만 선택할 수 있다.
3. 이동 중에는 정보량을 최소화한다.
4. 실제 경복궁 공간보다 UI가 앞서지 않는다.
5. 긴 역사 설명보다 핵심 맥락을 우선한다.
6. 역사적 사실은 검수된 콘텐츠를 기반으로 한다.
7. 공간 관람을 방해하지 않는 최소한의 방향 안내만 제공한다.

# 23. AI 역할

궁온에서 AI는 역사적 사실 자체를 자유롭게 생성하는 역할이 아니다.

## 기본 원칙

> **AI는 전문가가 검수한 역사 콘텐츠를 기반으로 선택 · 구성 · 표현 방식을 조정한다.**

- 현재 전각
- 페르소나와 공간의 관계

### 역할

- 필요한 콘텐츠 선택
- 정보 우선순위 조정
- 페르소나 관점에 맞는 표현 구성

---

## 23.2 역사적 사건 기반 AI

AI는 현재 공간과 연결된
검수된 대표 역사 사건을 불러와 사용자에게 제공한다.

### Flow

```text

↓
검수된 역사 사건 탐색

대표 사건 선택
↓
장면과 핵심 맥락 구성
↓
사용자에게 제공
```

### 핵심

AI는 역사 자체를 창작하지 않는다.

> **사용자가 자신의 관람 경험을 개인화된 실물로 남기고 싶을 때 선택적으로 구매하는 상품**

관람이 끝난 뒤에도
경복궁에서의 경험을 일상에서 다시 떠올리게 한다.

# 46. 최종 서비스 원칙

1. 실제 경복궁이 경험의 중심이다.
2. 디지털 시스템은 실제 공간을 대체하지 않는다.
3. 하나의 터치포인트에는 하나의 핵심 역할을 둔다.
4. 페르소나 선택은 Smart Glass에서만 진행한다.
5. Smart Glass는 1인칭 시점으로 유지한다.
6. 페르소나는 왕 / 왕비 / 세자만 사용한다.
7. 페르소나 기반 해석과 역사적 사건 기반 콘텐츠를 구분한다.
8. 역사 콘텐츠는 전문가 검수를 기반으로 한다.
9. AI가 역사적 사실을 임의로 생성하지 않는다.
10. Interactive Screen은 행동 중심으로 구성한다.
11. 프로그램 참여는 선택 사항이다.
12. Web에서는 관람 현황과 기록을 중심으로 제공한다.
13. Custom Goods는 무료 보상이 아니라 선택 구매 상품이다.
14. 엽전과 Digital Stamp는 사용하지 않는다.
15. 디지털 오류가 실제 경복궁 관람을 중단시키지 않도록 한다.

# 50. 최종 서비스 정의

> **궁온은 웹에서 관람의 전후를 연결하고,
> 스마트 글라스에서 역사 속 인물의 시선과 실제 공간의 역사적 사건을 해석하며,
> 인터랙티브 스크린에서 공간의 기능을 행동으로 직접 경험하게 하고,
> 관람 후에는 기록과 선택형 커스텀 굿즈를 통해 경험을 일상까지 이어주는 경복궁 관람 시스템이다.**
