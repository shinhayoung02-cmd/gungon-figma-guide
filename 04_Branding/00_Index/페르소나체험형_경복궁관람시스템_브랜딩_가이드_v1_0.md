# 브랜딩 필요 항목 전체 정리 (VER 1.0)

> 현재 서비스명과 브랜드 아이덴티티는 **미정(TBD)**이다.  
> 이 문서는 브랜딩을 진행할 때 필요한 전체 항목과 작업 순서를 정리한 체크리스트다.

---

# STEP 1. Brand Strategy

브랜드가 **왜 존재하고, 누구를 위해, 어떤 차별점을 가지고, 어떤 인상을 줄 것인지** 정의하는 단계.

## 1. Brand Purpose
- 브랜드가 존재하는 이유
- 해결하려는 경험적 문제
- 사용자의 관람 경험을 어떻게 바꾸려는지

## 2. Target
### Primary Target
- 핵심 사용자
- 연령
- 내·외국인 여부
- 관람 목적
- 문화유산 관심도
- 디지털 경험 친숙도

### Secondary Target
- 확장 사용자

## 3. Brand Positioning
- 기존 도슨트와 무엇이 다른가
- 일반 AR/VR 관람과 무엇이 다른가
- 게임형 역사 콘텐츠와 무엇이 다른가
- 이 서비스만의 차별적 위치

## 4. Brand Essence
브랜드를 한 단어 또는 한 개념으로 압축.

예시 방향:
- Perspective
- View
- Role
- Time
- Encounter
- Awakening

## 5. Brand Values
브랜드가 경험을 설계할 때 지켜야 할 핵심 가치.

현재 1차안:
- Perspective / 관점
- Participation / 참여
- Immersion / 몰입
- Authenticity / 진정성

## 6. Brand Personality
브랜드가 어떤 인상과 태도를 가져야 하는지 정의.

필요한 Personality Axis:
- 전통적 ↔ 미래적
- 학술적 ↔ 경험적
- 엄숙함 ↔ 친근함
- 정적 ↔ 역동적
- 장식적 ↔ 절제된
- 판타지 ↔ 역사적
- 설명적 ↔ 발견적

### 현재 1차안
- 몰입감 있는
- 호기심을 자극하는
- 정제된
- 현대적으로 해석된

# STEP 2. Naming & Verbal Identity

브랜드 전략을 실제 이름과 언어로 전환하는 단계.

## 7. Naming Criteria
이름을 평가할 기준.

- 경복궁/궁궐 경험과 연결되는가
- 외국인도 발음하기 쉬운가
- 너무 전통적이거나 촌스럽지 않은가
- 지나치게 기술 서비스처럼 보이지 않는가
- Persona / Perspective / Experience 개념과 연결되는가
- 한글·영문 병기가 자연스러운가
- 다른 서비스와 구분되는가
- 확장 가능성이 있는가

## 8. Naming Direction
후보를 만들기 전 의미 방향을 나눈다.

예시:
- 시선 / 관점
- 역할 / 인물
- 시간 / 과거
- 궁 / 공간
- 열다 / 깨우다
- 연결 / 이어짐
- 발견 / 다른 모습

## 9. Naming Candidates
- 10~20개 후보
- 의미
- 발음
- 영문 표기
- 장단점

## 10. Shortlist
3~5개 후보로 축소.

평가 항목:
- 의미 적합성
- 기억성
- 발음성
- 시각화 가능성
- 차별성
- 서비스 확장성

## 11. Final Naming
- 최종 브랜드명
- 영문명
- 표기 규칙
- 이름의 의미
- 선정 이유

---

# STEP 3. Verbal Identity

브랜드가 사용자와 어떤 말투로 대화할지 정의.

## 12. Brand One-liner
브랜드를 한 문장으로 설명.

## 13. Brand Story
- 브랜드가 왜 시작되었는지
- 어떤 경험을 만들고 싶은지
- 어떤 관람 방식을 제안하는지

## 14. Slogan
짧고 기억 가능한 핵심 문장.

## 15. Tone of Voice
### 정의해야 할 것
- 친근함 정도
- 역사 설명의 무게감
- 외국인 대상 문장 난이도
- Smart Glass 문체
- Web 문체
- Program 문체

### 피해야 할 방향
- 지나치게 학술적
- 지나치게 놀이공원식
- 과장된 판타지
- 장황한 역사 설명

### 권장 방향
> **차분하지만 몰입감 있고, 짧고 직관적인 이야기형 문체**

# STEP 4. Visual Concept

브랜드 전략을 시각 언어로 번역하는 단계.

## 16. Visual Keyword
브랜드를 시각적으로 표현할 핵심 개념.

후보 방향:
- Perspective
- Layer
- Frame
- Window
- Portal
- Trace
- Time
- Palace Grid
- Architecture
- Dancheong Geometry

## 17. Mood & Tone
- 전통과 현대의 비율
- 고급감
- 친근함
- 몰입도
- 공간성과 디지털성의 균형

## 18. Moodboard
필요 이미지:
- 경복궁 건축 디테일
- 창호
- 단청
- 전통 문양
- 궁궐 공간의 깊이
- AR Layer
- 투명 UI
- 현대 전시/문화공간 그래픽

# STEP 5. Visual Identity

실제 브랜드 시스템을 제작하는 단계.

## 19. Logo
- Symbol
- Wordmark
- Combination Mark
- Minimum Size
- Clear Space

## 20. Color Palette
- Primary
- Secondary
- Accent
- Background
- Dark / Light
- Digital / Spatial 사용 규칙

## 21. Typography
- Korean
- English
- Display
- Body
- Smart Glass용 크기/가독성 고려

## 22. Graphic Motif
브랜드를 반복해서 인식시키는 시각 요소.

예:
- 시선 프레임
- 겹쳐지는 레이어
- 창호 구조
- 궁궐 축선
- Persona별 작은 패턴

## 23. Iconography
- 선 굵기
- 모서리
- Fill / Outline
- 역사 모티프 사용 방식
- UI와 공간 Signage 통일

## 24. Image Direction
- 사진 스타일
- 역사 장면 표현 방식
- 3D / Illustration 사용 규칙
- 실사와 AR 합성 톤

# STEP 6. Persona Sub Identity

Persona는 브랜드 안에서 서로 다른 관람 시점을 제공하므로 작은 하위 시스템이 필요하다.

## 25. Persona System
예:
- 왕
- 왕비
- 세자
- 궁녀

각 Persona별 정의 가능 요소:
- Symbol
- Accent Color
- Pattern
- Short Descriptor
- Sound Cue
- AR Highlight Style

### 주의
Persona마다 완전히 다른 브랜드를 만들지 않는다.

> **Master Brand는 하나, Persona는 Variation**

# STEP 8. Smart Glass Brand Language

이 프로젝트에서 가장 중요한 브랜드 적용 영역 중 하나.

브랜드 그래픽이 곧 **인터페이스 언어**가 된다.

## 28. Smart Glass Visual Language
정의 항목:
- Persona 표시
- 공간명 Label
- Historical Scene 표시
- Object Highlight
- Focus Point
- Program Entry Signal
- 완료 Signal
- Safety / Pause State

## 29. AR Graphic Rule
- 실제 공간을 얼마나 가릴 것인가
- 정보 투명도
- 텍스트 양
- Layer 깊이
- Persona별 차이
- 역사 장면과 UI의 구분

- Persona Card
