## ① 기억의 2가지 시각

| 카드 | 내용 |
|---|---|
| Explicit Memory | 경복궁에서 실제로 보는 것 — *What I saw.* |
| (두 번째 카드) | **비어 있음** — Implicit Memory 자리로 보이나 텍스트 미작성 |

### 수집 원칙
- 사용자가 **본 정보**를 수집한다 → ✗
- 사용자가 **무엇에 관심을 보였는지**를 수집한다 → ○
- → 그 관심과 실제 공간 정보를 결합해서 **사용자가 놓친 것**을 만들어낸다.
- 이걸 좀 더 편하게 부르기 위해 **"정보의 갭"** 이라고 부름.

### 3요소 역할 정의
- **Smart Glass** = 여행 중 나를 관찰하는 눈
- **AI system** = 내가 놓친 것을 해석하는 기억 편집자
- **NFC 굿즈** = 다시 발견하는 물리적 키

## ② 굿즈 컨셉

- 슬로건(안): **TIE A MEMORY, UNTIE WHAT YOU MISSED**
- 기억을 묶어두는 **OBJECT**
  - 노리개의 **매듭(KNOT)** 에서 의미를 확장한다.
  - 여행의 순간과 현재의 나를 연결하고, 흩어진 기억 속에서 새로운 정보를 다시 풀어낸다.

### 형태
- 3번째 로고 시안 활용 굿즈 (매듭 + 로고 + 커스텀)
- 전통 문양 **챰**에 끈(매듭)을 더한 심플하고 현대적인 **키링** 형태
- 기호에 따라 다르게 묶을 수도 있고 끈도 바꿔 낄 수 있음
  - (그럴 수도 있다는 거고 **디폴트는 완제품으로 판매** 예정)
- 챰에 **NFC 기능 탑재**
- 키링 시안 3종(키링1/2/3) + 참고 이미지 2장 배치됨, **스케치 영역은 자리만 잡힌 상태**("여기에 스케치가 들어갈 예정")

## ③ 정보의 갭과 리마인드의 연결

> 사용자가 남긴 경험 + 경복궁의 정보 + 귀국 후의 맥락

### 경험 구조도 — SEE → CAPTURE → INTERPRET → REDISCOVER
1. **SEE** — 경복궁에서 경험
2. **CAPTURE** — 스마트 글래스가 사용자의 관심/행동을 관찰
3. **INTERPRET** — 사용자가 본 것과 보지 않은 것을 구분, AI가 새로운 정보와 연결 후 사용자 경험과 가공
4. **REDISCOVER** — 여행 후 굿즈가 그 정보를 다시 열어줌

### 정보의 종류 (4단계)
| # | 구분 | 정의 | 역할 | 카피 |
|---|---|---|---|---|
| 1 | REMEMBER | 내가 경험했던 것 | 기본 리마인드 | **WHAT YOU SAW** — 내가 가장 오래 본 장소 → 사진 속 숨겨진 건축 디테일 |
| 2 | NOTICE | 내가 봤지만 못 알아챈 것 | 핵심 리마인드 | **WHAT YOU MISSED** — 내가 봤지만 놓친 디테일 → 당시에는 몰랐던 문화적 의미 |
| 3 | DISCOVER | 내가 전혀 몰랐던 것 | 여행을 정보로 연장 | **WHAT YOU DIDN'T KNOW** — 그 장소에 대한 새로운 이야기 → 내가 지나쳤던 장소의 정보 |
| 4 | CONNECT | 현재의 나와 연결 | 여행을 현재로 연장 | **WHAT CONNECTS** — 한국의 건축/문화와 내 나라의 비슷한 요소 → 내가 관심을 보인 대상과 연결된 새로운 이야기 |

→ 종착점: **YOUR SECOND VISIT** — 내 여행 데이터를 바탕으로 만들어진 새로운 경복궁 이야기 → 나의 시선으로 가공된 개인화 경험

### 수집되는 정보 (Smart Glass)
| 소스 | 무엇을 수집 |
|---|---|
| GPS | 어디에 있었는가 |
| Camera | 무엇을 촬영했는가 |
| Voice | 무엇을 궁금해했는가 |
| AR Interaction | 어떤 정보에 반응했는가 |
| Eye Tracking | 무엇을 관심있게 바라보았는가 |

### 매칭 트리거 목록
날씨 · 날짜 · 위치 · 계절 · 사진 · 음악 · 음식 · 여행 · SNS · 언어

## ④ 리마인드 방식 (3가지)

### 1. NFC 태그
사용자가 일상생활 속에서 굿즈를 보거나 특정 상황을 경험했을 때 **직접 태그하여** 기억을 꺼내는 방식

**주요 상황**
- 여행에서 사용한 가방을 사용할 때 → 오늘의 한국 여행 기억을 랜덤으로 보여준다. 경복궁, 한복, 음식, 서울의 거리 등 다양한 여행 콘텐츠 활용.
- 여행 사진을 정리할 때 → 당시 경복궁에서 찍었던 사진을 보여준다. 사진을 찍었던 장소와 당시의 짧은 이야기를 함께 제공.

### 2. 리마인드 알람
사용자가 직접 태그하지 않아도 **서비스가 특정 시점에** 여행의 기억을 먼저 알려주는 방식

**주요 상황**
- 경복궁 방문 1개월 후 → "한 달 전, 당신은 한국에 있었습니다." + 당시 찍은 경복궁 사진
- 경복궁 방문 1년 후 → "1년 전 오늘, 당신은 경복궁에 있었습니다." + 가장 기억에 남는 사진/여행 기록
- 생일 또는 특별한 날 → 여행 중 남긴 메시지와 사진. 한국에서의 특별한 순간을 다시 떠올릴 수 있도록.
- 한국에 다시 방문했을 때 → "Welcome back to Korea." + 이전 한국 여행의 사진과 방문 기록

### 3. 메일
여행의 순간을 **하나의 기록으로 정리**하여 사용자가 시간을 가지고 다시 돌아볼 수 있도록 하는 방식

**주요 상황**
- 한국 여행을 마친 직후 → 귀국 후 1~3일 이내에 여행 기록 전달. 방문했던 경복궁, 먹었던 음식, 입었던 한복, 서울에서 찍은 사진 등을 하나의 '나의 한국 여행'으로 구성.
- 다음 여행을 준비할 때 → 이전 한국 여행의 기록을 다시 보여준다. 과거에 방문했던 장소나 다시 가고 싶은 장소를 확인할 수 있도록.
