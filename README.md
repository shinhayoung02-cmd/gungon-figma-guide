# GUNG:ON Figma 가이드

GUNG:ON(페르소나 체험형 경복궁 관람 시스템) 발표자료 Figma 작업을 위한 공용 가이드입니다.

## 덱 구조

원본 25장 기획, 확인된 top-level 프레임 23개(1~23번):

1. **01 시스템 기획** (S3~13, 11장) — 프로젝트 정의 → 문제정의(HMW) → 선택과 집중(Before/Final) → 최종 서비스 구조(Web/Smart Glass/Interactive Screen) → 터치포인트별 역할+유저플로우 → 각 기기 상세 → 운영 시나리오 → 관람 전중후 → 이해관계자 구조(조직도)
2. **02 브랜드 전략** (S14~16)
3. **03 네이밍·언어체계** (S17~18)
4. **04 브랜드 무드보드** (S19~21)
5. **05 색상 정의** (S22~)

알려진 원본 자체 불일치(의도적으로 손대지 않음): S1 푸터에 "1/13" 잔존(13장→25장 확장 흔적), S2 목차의 슬라이드 범위 텍스트가 실제 헤더와 불일치, 24/25번 프레임은 아직 미확인.

## 레이아웃 템플릿 6종

새 슬라이드가 필요하면 아래 6종 중 내용 성격에 맞는 걸 골라서 만듭니다.

| 유형 | 구조 | 예시 슬라이드 |
|---|---|---|
| 표지형 | 중앙정렬 태그+대제목2줄+구분선+서브텍스트 | S1 |
| 목차형 | 좌측 로고/설명, 우측 01~05 번호+섹션명+범위 리스트 | S2 |
| **1번** (좌측 텍스트+우측/하단 모듈형, 기본형) | 좌측 고정 대제목2줄+설명, 우측/하단은 카드그리드·매트릭스표·프로세스박스·조직도트리 등으로 자유 교체, 하단 인사이트바 자주 동반 | S3,4,7,10,13,14,15,16,17,18,22 |
| **2번** (상단 전체폭 타이틀+하단 카드/스텝형) | 제목이 상단 전체폭, 아래 카드/스텝을 화살표로 연결(Before→Final, 단계흐름, 유저플로우, 타임라인) | S5,6,8,9,11,12,20 |
| **3번** (이미지·무드보드 중심형) | 텍스트 최소, 이미지/컬러칩 콜라주 위주 | S19, S21 |
| **4번** (데이터·컬러 그리드형) | 스와치/컬러스케일/시맨틱표 등 격자형 데이터 | S22, S23 |

### 번호 지정 없이 요청할 때 판단 기준

- 텍스트 설명 위주 + 카드/표/리스트 하나 → **1번** (기본값)
- 비교·프로세스·단계 흐름이 핵심 → **2번**
- 비주얼·무드가 중심인 콘텐츠 → **3번**
- 색상표·수치·매트릭스 등 데이터 나열 중심 → **4번**
- 애매하면(1번/2번 둘 다 가능해 보이는 등) 임의로 정하지 말고 먼저 확인한다. 명확하면 확인 없이 바로 진행한다.

## 공통 디자인 토큰

새로 만들지 말고 아래 값을 그대로 재사용합니다.

- 프레임 1920×1080, 좌우 여백 115px
- 헤더 72px, 3컬럼(로고·타이틀 | 섹션제목 2줄 중앙 | GUNG:ON 워드마크), 하단 보더 `#E0E0E0`
- 푸터: 좌 저작권 텍스트, 우 페이지번호
- 대제목 54px ExtraBold / 부제 20px Medium `#595959` / 구분선 1px `#D9DCE0` / 본문 20px Regular `#595959`
- 카드: 흰 배경, border `#E5E5E5`, radius 12px
- 인사이트/Key Takeaway 바: 배경 `#F2F3F4`, radius 12px
- 포인트컬러 레드 `#DD3944`, 그레이 `#747A83` / `#595959`
- 폰트: 원본은 Pretendard. 단, 위 Figma 파일에는 Pretendard가 설치돼 있지 않아 플러그인 스크립트로 텍스트를 만들 때 로드가 안 됨 — 현재는 `Noto Sans KR`(Black/Bold/Medium/Regular)로 대체 중. Figma 프로젝트에 Pretendard를 설치하면 원복 가능.

## GUNG:ON 서비스 기획 핵심

슬라이드 내용을 다루거나 재구성할 때 반드시 유지해야 하는 기준입니다.

- **3대 터치포인트**: Web(안내·현황·기록, Smart Glass 연결/관리 기능 없음) / Smart Glass(선택·관람·해석, 왕·왕비·세자 1인칭 고정) / Interactive Screen(행동·체험, 프로그램은 "오늘의 수라상"·"훈민정음 서재" 2개만)
- **선택형 Custom Goods**: 무료 보상 아님(엽전/Digital Stamp/무료굿즈 없음), 체험 결과 반영한 개인화 굿즈를 "선택 구매"
- **금지 표현**: "웹→스마트글라스 연결" 계열 문구, GPS, NFC, AI 동선, 지도기반 Web, 실물 엽전, Digital Stamp, 무료 굿즈, Persona 3인칭 시점, 왕/왕비/세자 외 페르소나 (BEFORE 과거기획 영역 표시는 허용, FINAL 구조엔 금지)
